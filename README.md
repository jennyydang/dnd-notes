# Adventurer's Log

A D&D campaign notes app built with React and SCSS. Organizes your session
notes into three tabs:

- **Maps** — upload and browse map images shared by your DM, with a
  full-size lightbox view.
- **NPCs** — track name, race, where you met them, and life status
  (Alive / Deceased / Unknown / Missing).
- **Loot** — log items, where you found them, and free-form notes.

All data is saved to your browser's `localStorage`, so your notes persist
between sessions without needing a backend.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint
